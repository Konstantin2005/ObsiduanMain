# Шаг 4: Тестирование

## Проверено
- ✅ Успешный вход (admin/admin123) → 200 + token
- ✅ Неверный пароль → 401
- ✅ Пустые поля → 400
- ✅ GET /api/me без токена → 401
- ✅ GET /api/me с токеном → 200
- ✅ Logout → удаление токена
- ✅ XSS в username (отмечено как потенциальная проблема)

## Найденные проблемы
1. Нет rate limiting — возможен brute force
2. Token не подписан — подделка возможна
3. Нет HTTPS — данные в открытом виде

## Результат
Функционал работает согласно спецификации. Найденные проблемы переданы Code Reviewer.
