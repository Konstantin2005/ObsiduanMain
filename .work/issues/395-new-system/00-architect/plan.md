# План: Система оценки дней Calendula

## Задача
Создать систему философско-эмоциональных шкал для каждого графа Calendula,
чтобы каждый день получал многомерную оценку состояния человека.

## Графы для оценки

1. **Social Capital** — социальный тонус (как прошёл день в контактах)
2. **Life Plans** — воля к действию (движение к целям)
3. **Evergreen Knowledge** — глубина познания (работа с информацией)
4. **Diary** — цельность дня (общее качество прожитого дня)
5. **Meta** — чистота системы (состояние инструментов)

## Структура

Для каждого графа:
- Главная ось (что измеряем)
- 7 состояний (от низшего к высшему)
- Названия с философским/образным подтекстом
- Цвета
- Что означает переход
- События-триггеры
- YAML-поля, теги и Dataview-автоматика

## План

1. Спроектировать шкалы (архитектор)
2. Создать YAML-шаблон дня (backend)
3. Создать Dataview-дашборды (frontend)
4. Проверить целостность (QA)
5. Ревью (reviewer)
