Тест-кейсы для заметок и управления документами для API разработки

## Обзор тестирования

Этот файл содержит эталонные тесты для системы заметок и управления документами. Все тесты охватывают основные функции, которые были определены в архитектуре Architect.

## 1. Тест-кейсы для API заметок

### 1.1. Заметки

#### TC-NOTE-001: Создание новой заметки
- **Описание:** Создание новой заметки с минимальными полями
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Тестовая заметка", "content": "Содержание заметки", "syntax": "markdown"}
- **Ожидаемый результат:** 201 Created, возвращает заметку с ID

#### TC-NOTE-002: Получение заметки по ID
- **Описание:** Получение существующей заметки
- **Действие:** GET /api/notes/{id}
- **Входные данные:** {"id": "uuid-123"}
- **Ожидаемый результат:** 200 OK, возвращает заметку

#### TC-NOTE-003: Обновление заметки
- **Описание:** Обновление существующей заметки
- **Действие:** PUT /api/notes/{id}
- **Входные данные:** {"title": "Обновленная заметка", "content": "Обновленное содержимое"}
- **Ожидаемый результат:** 200 OK, возвращает обновленную заметку

#### TC-NOTE-004: Удаление заметки
- **Описание:** Удаление заметки
- **Действие:** DELETE /api/notes/{id}
- **Входные данные:** {"id": "uuid-123"}
- **Ожидаемый результат:** 204 No Content

#### TC-NOTE-005: Экспорт заметки
- **Описание:** Экспорт заметки в различных форматах
- **Действие:** POST /api/notes/{id}/export
- **Входные данные:** {"format": "markdown"}
- **Ожидаемый результат:** 200 OK, возвращает файл

#### TC-NOTE-006: Список заметок с пагинацией
- **Описание:** Получение списка заметок с пагинацией
- **Действие:** GET /api/notes
- **Входные данные:** {"page": 1, "limit": 10, "sort": "created_at"}
- **Ожидаемый результат:** 200 OK, возвращает список с метаданными пагинации

#### TC-NOTE-007: Поиск заметок
- **Описание:** Поиск заметок по содержимому
- **Действие:** GET /api/notes?search=query
- **Входные данные:** {"search": "контент"}
- **Ожидаемый результат:** 200 OK, возвращает найденные заметки

#### TC-NOTE-008: Фильтрация заметок
- **Описание:** Фильтрация заметок по тегам и меткам
- **Действие:** GET /api/notes?tags=tag1,tag2&labels=label1
- **Входные данные:** {"tags": ["tag1", "tag2"], "labels": ["label1"]}
- **Ожидаемый результат:** 200 OK, возвращает отфильтрованные заметки

#### TC-NOTE-009: Работа с синтаксисами
- **Описание:** Создание заметки с пользовательским синтаксисом
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Заметка", "content": "Контент", "syntax": "custom"}
- **Ожидаемый результат:** 201 Created, синтаксис обрабатывается плагином

#### TC-NOTE-010: Контексты
- **Описание:** Управление контекстами
- **Действие:** CRUD операции для контекстов
- **Входные данные:** {"title": "Контекст", "description": "Описание контекста"}
- **Ожидаемый результат:** 200 OK для всех CRUD операций

## 2. Edge Case тест-кейсы

### 2.1. Обработка исключений

#### TC-EDGE-001: Создание заметки без title
- **Описание:** Создание заметки без обязательного поля title
- **Действие:** POST /api/notes
- **Входные данные:** {"content": "Только содержимое"}
- **Ожидаемый результат:** Ошибка валидации (400 Bad Request)

#### TC-EDGE-002: Создание заметки с пустым content
- **Описание:** Создание заметки с пустым содержимым
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Пустое содержимое", "content": ""}
- **Ожидаемый результат:** 201 Created (допустимо)

#### TC-EDGE-003: Обновление несуществующей заметки
- **Описание:** Обновление заметки с несуществующим ID
- **Действие:** PUT /api/notes/invalid-id
- **Входные данные:** {"title": "Обновление"}
- **Ожидаемый результат:** 404 Not Found

#### TC-EDGE-004: Удаление несуществующей заметки
- **Описание:** Удаление заметки, которая уже была удалена
- **Действие:** DELETE /api/notes/{id}
- **Входные данные:** {"id": "uuid-deleted"}
- **Ожидаемый результат:** 404 Not Found

#### TC-EDGE-005: Экспорт несуществующей заметки
- **Описание:** Экспорт заметки с несуществующим ID
- **Действие:** POST /api/notes/invalid-id/export
- **Входные данные:** {"format": "pdf"}
- **Ожидаемый результат:** 404 Not Found

### 2.2. Корректность данных

#### TC-EDGE-006: Теги и метки с особыми символами
- **Описание:** Создание заметки с тегами и метками, содержащими специальные символы
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Тест", "content": "Контент", "tags": ["tag#1", "tag@2"], "labels": ["label_3", "label.4"]}
- **Ожидаемый результат:** 201 Created

#### TC-EDGE-007: Длинные поля
- **Описание:** Создание заметки с очень длинным title (более 255 символов)
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "A".repeat(256), "content": "Контент"}
- **Ожидаемый результат:** Ошибка валидации (400 Bad Request)

#### TC-EDGE-008: Пустые синтаксисы
- **Описание:** Обработка пустого синтаксиса
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Тест", "content": "Контент", "syntax": ""}
- **Ожидаемый результат:** 201 Created (используется синтаксис по умолчанию)

#### TC-EDGE-009: Пустая папка файлового сервера
- **Описание:** Обработка запроса к существующей папке файлового сервера
- **Действие:** GET /api/static/documents/
- **Входные данные:** N/A
- **Ожидаемый результат:** 200 OK, возвращает пустой список

#### TC-EDGE-010: Квоты базы данных
- **Описание:** Создание большого количества заметок
- **Действие:** POST /api/notes (сериализовано)
- **Входные данные:** 1000 заметок
- **Ожидаемый результат:** 201 Created для первой заметки, последующие может дать ошибку

### 2.3. Синхронизация данных

#### TC-EDGE-011: Одновременное создание заметок
- **Описание:** Создание одинаковых заметок с одинаковыми ID
- **Действие:** POST /api/notes (параллельно)
- **Входные данные:** {"id": "same-id", "title": "Заметка"}
- **Ожидаемый результат:** 201 Created для первой, 409 Conflict для второй

#### TC-EDGE-012: Обновление с конкурентными версиями
- **Описание:** Конкурентное обновление одной заметки
- **Действие:** PUT /api/notes/{id} (параллельно)
- **Входные данные:** Несколько обновлений с разными версиями
- **Ожидаемый результат:** 200 OK для первого, 409 Conflict для последующих

- **Описание:** Обработка недоступности файлового сервера
- **Действие:** GET /api/static/documents/file.txt
- **Входные данные:** N/A
- **Ожидаемый результат:** 503 Service Unavailable

#### TC-FAIL-002: Ошибка синхронизации файлового сервера
- **Описание:** Обработка ошибки синхронизации файлового сервера
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Тест", "content": "Контент"}
- **Ожидаемый результат:** 202 Accepted (очередь на повторную попытку)

#### TC-FAIL-005: Ошибка парсинга синтаксиса
- **Описание:** Обработка блокирующего парсера синтаксиса
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Тест", "content": "Синтаксис с ошибкой", "syntax": "broken"}

#### TC-FAIL-006: Проблемы с обработчиком синтаксиса

### 3.3. Ошибки кэширования

- **Действие:** GET /api/notes/invalid-uuid

- **Описание:** Валидация формата даты в метаданных заметок
- **Действие:** POST /api/notes
- **Входные данные:** {"title": "Тест", "created_at": "2023-13-40"}
- **Ожидаемый результат:** Ошибка валидации (400 Bad Request)

#### TC-VALID-004: Разрешения
- **Описание:** Проверка ограничений на основе ролей для удаления заметки

- **Входные данные:** {"user_id": "user1", "role": "reader"}
