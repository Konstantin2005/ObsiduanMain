# Контрольная неделя: проверка гипотезы

**05-07 — 11-07-2026**  
**Основание:** [[vault/note/weekly-hypothesis-2026-07-04]]

---

## Цель недели

Не сделать как можно больше.  
Не улучшить систему.  
Не найти новый метод.  

А получить **честный ответ** на вопрос: *увеличится ли количество завершённых задач, если я неделю не буду менять систему организации?*

---

## Правила

### 1. 🔒 Заморозить Obsidian

**Нельзя:**
- менять структуру дневников
- делать новые графы
- создавать новые шаблоны
- придумывать новые методологии/абстракции
- улучшать существующую систему

**Можно:**
- писать дневник
- создавать обычные заметки
- записывать идеи в Inbox (не реализуя)

### 2. 🔒 Не начинать новые проекты

Любая новая идея → записать. Закрыть. Вернуться к текущей задаче.

Актуальные проекты: Java, English, LeetCode, Calendula (только ведение), Delta.

### 3. ✅ Каждый день — одно завершение

В конце дня одна строка в дневнике:

> ЗАВЕРШЕНИЕ: [что конкретно закончил]

Если ничего: `ЗАВЕРШЕНИЕ: НИЧЕГО`

---

## Минимум на каждый день

- [x] Написать дневник
- [x] Завершить хотя бы одну небольшую задачу
- [x] Записать новые идеи, но не реализовывать
- [x] Написать строку "ЗАВЕРШЕНИЕ:"

---

## Ежедневный трекинг

Каждый вечер в последней заметке дня:

```
ЗАВЕРШЕНИЕ: ...
НОВЫЕ ИДЕИ: ...
РЕАЛИЗОВАЛ НОВУЮ ИДЕЮ?: Да / Нет
ХОТЕЛОСЬ ИЗМЕНИТЬ СИСТЕМУ?: Да / Нет
СЛОЖНОСТЬ ПРОДОЛЖЕНИЯ СТАРОЙ ЗАДАЧИ (1-10): ...
```

---

## Критерии успеха (12 июля)

- [ ] Меньше 3 дней с "НИЧЕГО"
- [ ] 0 новых систем создано
- [ ] 0 новых проектов начато
- [ ] Хотя бы 5 завершённых задач за неделю
- [ ] Дневник ведётся каждый день

---

## Что делать, если захочется что-то поменять

Один вопрос:

> Изменение системы приблизит завершение текущей задачи сегодня?

Если ответ **"Нет, но потом будет удобнее"** — изменение откладывается до следующего отчёта.
