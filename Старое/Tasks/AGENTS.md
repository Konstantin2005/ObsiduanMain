# Kanban Workflow

## Auto-move tasks from "Запланировано" to "Сегодня"

`Move-TodayTasks.ps1` — PowerShell скрипт, который переносит задачи с сегодняшней датой из колонки **Запланировано** в колонку **Сегодня** в ежемесячном Kanban-файле.

### Использование

```powershell
# Запуск с сегодняшней датой (по умолчанию)
.\Move-TodayTasks.ps1

# Запуск с конкретной датой
.\Move-TodayTasks.ps1 -Date "2026-05-31"

# Указать путь к папке с Kanban файлами
.\Move-TodayTasks.ps1 -KanbanDir "C:\obsidian\Main\Calendula\План"
```

### Параметры

| Параметр     | По умолчанию                      | Описание                          |
| ------------ | --------------------------------- | --------------------------------- |
| `-Date`      | Сегодня (`yyyy-MM-dd`)            | Дата, задачи с которой переносить |
| `-KanbanDir` | `C:\obsidian\Main\Calendula\План` | Путь к папке с месячными досками  |

### Как это работает

1. Определяет текущий месяц и открывает соответствующий файл `YYYY - Месяц.md`
2. Находит в секции `## Запланировано` задачи с датой `@{YYYY-MM-DD}`
3. Удаляет их оттуда и добавляет в секцию `## Сегодня`
4. Сохраняет файл (UTF-8 без BOM)

### Планировщик Windows

Для автоматического запуска каждый день можно добавить задачу в Планировщик Windows:

- Триггер: ежедневно в 00:00
- Действие: `powershell.exe -File "C:\obsidian\Main\Scripts\Vault\Move-TodayTasks.ps1"`
- Working directory: `C:\obsidian\Main\Tasks`

### Важно

- Работает только с колонками **Запланировано** и **Сегодня**
- Распознаёт даты формата `@{2026-05-30}` и `@{2026-05-30} @@{20:00}`
- Файл должен существовать для текущего месяца

## Sort tasks between monthly boards

`Sort-BoardTasks.ps1` — проверяет все задачи во всех месячных досках и переносит их в правильный месяц по дате `@{YYYY-MM-DD}`.

### Использование

```powershell
.\Sort-BoardTasks.ps1
.\Sort-BoardTasks.ps1 -KanbanDir "C:\obsidian\Main\Calendula\План"
```

### Как это работает

1. Проходит по всем годовым папкам и месячным файлам
2. В каждом файле находит задачи, чей месяц/год не совпадает с файлом
3. Задачи с `@{2026-06-02}` в файле `2026 - Май.md` → перемещает в `2026 - Июнь.md`
4. Задачи с `@{2027-01-15}` в файле `2026 - Декабрь.md` → перемещает в `2027 - Январь.md`
5. Сохраняет все изменённые файлы (UTF-8 без БОМ)

### Известные баги (исправлены)

**Strip-Blank infinite loop** (исправлен): Вспомогательная функция `Strip-Blank` обрезает пустые строки в начале и конце массива. В PowerShell `$arr[1..0]` НЕ создаёт пустой массив, а генерирует `@(1, 0)` (два элемента), что приводило к бесконечному циклу при массиве из одного элемента.

**Фикс**: добавлена проверка `if ($arr.Count -eq 1) { return @() }` перед срезом.

## File Watcher (автоматическая сортировка в реальном времени)

`Watch-Kanban.ps1` — фоновый процесс, который следит за изменениями в папке `Calendula/План` и автоматически запускает `Sort-BoardTasks.ps1` при любом изменении файлов.

### Как работает

1. Запускается при входе в Windows (через ярлык в Startup, `run-watcher.vbs`)
2. Каждые 5 секунд проверяет `LastWriteTimeUtc` всех `.md` файлов в `Calendula/План/**`
3. При обнаружении изменений запускает `Sort-BoardTasks.ps1`
4. Защита от циклов: не запускается чаще раза в 30 секунд (cooldown).
   Без cooldown Sort-BoardTasks (который сам пишет файлы) вызвал бы вечный цикл.
5. Использует polling (Get-ChildItem + сравнение LastWriteTimeUtc), а не FileSystemWatcher,
   потому что `Register-ObjectEvent -Action` ненадёжен в неинтерактивных PowerShell процессах.
