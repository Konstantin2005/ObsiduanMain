```java
try { // Код, который может вызвать исключение // Например: деление на ноль, чтение файла и т.д. 
} catch (ExceptionType e) { // Код, который выполнится, если произошло исключение указанного типа // Здесь можно обработать ошибку 
}
```

### Ключевые моменты:

1. **Блок try** - содержит код, который может вызвать исключение
2. **Блок catch** - обрабатывает исключение, если оно произошло
3. **Объект исключения (e)** - содержит информацию об ошибке:


```java
try { // код с возможным исключением 
} catch (Exception e) { 
// обработка 
} finally { // этот код выполнится ВСЕГДА // независимо от того, было исключение или нет // обычно используется для освобождения ресурсов 
}
```
