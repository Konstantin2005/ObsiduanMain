Штуки которые управляют циклами. 
Либо пропустить иттерацию либо прервать исполнение вообще всего цикла.

Continue - он пропускает итерацию
```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // пропуск текущей итерации
    }
}
```

Break -  прерывает итерацию вообще 

```java
for (int i = 0; i < 10; i++) { 
	if (i == 5) { break; // выход из цикла 
	} 
}
```

В данном случае будет выполнен выход из цикла когда будет 5 иттерация
