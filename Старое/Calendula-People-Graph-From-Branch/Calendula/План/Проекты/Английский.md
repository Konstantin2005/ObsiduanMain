## 

- [ ] Дойти до уровня С1


## Чтение

- [ ] Чтение 250-300 часов
- [ ] A1-A2 
	Простые тексты, короткие предложения, Детские книги
- [ ] B1 
	Статьи среднего уровня, простые новости, короткие рассказы
- [ ] B2 Газеты, журналы, художественная литература, научно-популярные статьи
- [ ] C1 Академические тексты, классическая литература,


## 

- [ ] Слушание 300-350 часов
- [ ] A1-A2 Медленная, четкая речь. Детские видео, простые подкасты, диалоги на уроках
- [ ] B1 Нормальная скорость речи, новости, фильмы с субтитрами, подкасты для учащихся
- [ ] B2 Фильмы без субтитров, подкасты на интересующие вас темы, лекции, интервью
- [ ] C1 Сложные лекции, научные конференции, документальные фильмы, быстрая беседа носителей


## 

- [ ] Говорение 350-400 часов
- [ ] A1-A2 Произношение, простые фразы, представление себя, ответы на простые вопросы
- [ ] B1 Простые беседы, рассказы о себе, выражение мнений на простые темы, просьбы и предложения
- [ ] B2 Спонтанные дискуссии, дебаты, презентации, объяснение сложных идей. Меньше ошибок
- [ ] C1 Полностью спонтанная, беглая, грамотная речь


## 

- [ ] Письмо 150-200 часов
- [ ] A1-A2 Простые предложения, короткие сообщения, базовые структуры
- [ ] B1 mail среднего уровня, короткие истории, простые эссе, заполнение форм
- [ ] B2 Формальные письма, эссе с аргументацией, творческое письмо, отзывы
- [ ] C1 Академическое письмо, статьи, сложные деловые документы, творческое письмо профессионального уровня
