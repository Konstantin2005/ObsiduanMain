наша задача это реализивать функцию PersonGenerator которя будет выводить данные из массива в конось полиморфизным методом
```js
function personGenerator(data,fn) {  
    return function(...args){  
        fn.apply(data,args);  
    }  
}  
```
вот она она принимает данные и функцию 

а в замыкание мы вызываем фукуию и передаем ей туда данные из массива
