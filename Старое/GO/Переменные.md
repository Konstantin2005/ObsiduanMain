можно так сначала иницилизовать , а после дать ей значение
```Go
func main() {
    var i int

```

uint это положительные целые числа
```Go
- в `uint8` могут поместиться числа от 0 до 255;
- в `uint16` — от 0 до 65_535;
- в `uint32` — от 0 до 4_294_967_295;
- в `uint64` — от 0 до 18_446_744_073_709_551_615.
```
