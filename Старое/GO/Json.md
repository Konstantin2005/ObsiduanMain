
Ключи — это строковые переменные.
**Значение** — это содержимое передаваемого параметра.
Значением может быть строка, число, булево значение, массив, null и даже другой объект JSON. Вот пример последнего:
```JSON
{ "name": "Иван Иванов", 
"age": 37, 
"address": { 
"city": "Москва", 
"street": "Вавилова", 
"building": 17 
	}, 
"married": false 
}
```

```JSON
{ 
"artist": [ 
{"artist_name": "30 seconds to mars", "formed": "1998"}, 
{"artist_name": "Evanescence", "formed": "2003"}, 
{"artist_name": "Garbage", "formed": "1994"} 
	] 
}
```
