# ShadowValueSystem MOC

## Description
Map of Content for ShadowValueSystem vault - a knowledge graph exploring the hidden costs of values, their shadow sides, and the chain of consequences leading to wisdom.

## Цепочка ценностей
```
Value → Shadow → Corruption → Failure → Lesson
```

## Clusters

### Values (60 notes)
Базовые ценности и их описания

### Shadows (45 notes)
Теневые стороны каждой ценности

### Corruption (30 notes)
Порча/развращение ценностей

### Failure (30 notes)
Провал/неудача как следствие порчи

### Lesson (30 notes)
Уроки, извлечённые из провалов

### Behaviors (90+ notes)
Поведения, порождаемые теневыми сторонами

### Tradeoffs (30+ notes)
Диалектические пары ценностей
