# Открытость

## Описание
Открытость — это готовность принимать новый опыт, идеи и людей без защитных барьеров. Рождается из опыта [[Стена]], когда эмоциональные стены, возведённые для защиты, изолируют от мира.

## Цепочка
[[Уязвимость]] → [[Страх ранения]] → [[Эмоциональная изоляция]] → [[Стена]] → **[[Открытость]]**
