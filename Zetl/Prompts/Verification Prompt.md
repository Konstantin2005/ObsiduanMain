# Verification Prompt

> Промпт для проверки реализации графов

---

## Промпт

```
Проверь реализацию всех графов в C:\obsidian\Main\Zetl\.

## Что проверять

1. **Наличие MOC файла** - есть ли MOC*.md в каждой папке
2. **Наличие Navigation.md** - есть ли файл навигации
3. **Количество нод** - сколько .md файлов в каждом графе
4. **Связи** - есть ли ссылки на другие графы
5. **Стандарты** - соответствует ли структура шаблону

## Формат отчета

```markdown
# Отчет о реализации графов

## Общая статистика

| Метрика | Значение |
|---------|----------|
| Всего графов | 26 |
| Реализовано | N |
| Не реализовано | N |
| Процент готовности | N% |

## Детальный отчет

| Граф | Нод | MOC | Navigation | Связи | Статус |
|------|-----|-----|------------|-------|--------|
| Graph1 | 100 | ✅ | ✅ | ✅ | Готово |
| Graph2 | 200 | ❌ | ❌ | ❌ | Нужна доработка |

## Проблемы

1. [Граф] - [Описание проблемы]
2. [Граф] - [Описание проблемы]

## Рекомендации

1. [Рекомендация 1]
2. [Рекомендация 2]
```

## Критерии оценки

- ✅ Готово - есть MOC, Navigation, связи
- ⚠️ Частично - есть MOC, но нет Navigation
- ❌ Не реализовано - нет MOC
```

---

## Использование

1. Запусти скрипт проверки
2. Получи отчет
3. Исправь проблемы
4. Повтори проверку
