# Prompts

> Промпты для реализации графов

---

## Доступные промпты

| Промпт | Описание | Использование |
|--------|----------|---------------|
| [[Graph Implementation Prompt]] | Полный промпт для реализации всех графов | Основной |
| [[Quick Prompt]] | Компактный промпт | Быстрый старт |
| [[Script Generation Prompt]] | Промпт для генерации скрипта | Автоматизация |
| [[Verification Prompt]] | Промпт для проверки реализации | Контроль качества |

---

## Рекомендации

### Для ручной реализации
1. Используй [[Quick Prompt]]
2. Копируй в нейросеть
3. Проверяй результат

### Для автоматизации
1. Используй [[Script Generation Prompt]]
2. Запусти сгенерированный скрипт
3. Проверь [[Verification Prompt]]

### Для полной реализации
1. Начни с [[Graph Implementation Prompt]]
2. Следи за进度 по [[MOC - Graph Implementation Plan]]
3. Проверяй результат [[Verification Prompt]]
