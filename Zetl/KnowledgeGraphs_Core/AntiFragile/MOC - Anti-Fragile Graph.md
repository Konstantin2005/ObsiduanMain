# Anti-Fragile Graph

> Граф, который усиливается при разрушении.
> Нет деревьев, линий, изоляции.
> Каждый узел — часть живой, дышащей сети.

## Принципы anti-fragility

1. **Нет единой точки отказа** — удаление любого узла не разрушает сеть
2. **Избыточность** — каждый узел связан минимум с 7 другими
3. **Кластеризация** — узлы группируются по темам
4. **Мосты** — кластеры связаны друг с другом
5. **Резервные маршруты** — длинные связи для обхода повреждений
