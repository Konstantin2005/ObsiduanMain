## Как использовать

1. **Начни с Gnosis** — базовые концепции знания
2. **Перейди к Ethos** — этическая основа
3. **Изучи Kairos** — временная структура
4. **Погрузись в Psyche** — внутренний мир
5. **Пойми Antinomy** — противоречия
6. **Найди Nexus** — связи между графами
