### По графам

- 🌌 [[MOC - KnowledgeGalaxy]] — **Структурированная вселенная знаний** — Мультисистемный подход к объединению разрозненных знаний через иерархическую систему категорий и кросс-ссылок.
- 📚 [[MOC - Knowledge]] — **Сеть фактов, концепций и теорий** — Центральный граф для организации базовых знаний.
- 🎯 [[MOC - DecisionMakingGraph]] — **Деревья решений с последствиями** — Граф для моделирования принятия решений.
- ❓ [[MOC - QuestionFractal]] — **Исследовательский фрактал открытых вопросов** — Граф для изучения неизвестного.
- ⚖️ [[MOC - BiasGraph]] — **Двойная структура предубеждений и их теней** — Граф для понимания предубеждений.
- 🧠 [[MOC - PersonalityGraph]] — **Архетипы, черты характера, паттерны поведения** — Граф для понимания личности.

## Межграфовые переходы

Чтобы перейти из одного графа в другой:

1. Найдите мостовую заметку в текущем графе
2. Перейдите по `[[MOC - TargetGraph]]` в другой граф
3. Используйте graph view для визуализации связей
