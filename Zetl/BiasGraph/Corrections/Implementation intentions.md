# Implementation intentions

## Описание

Формулирование конкретных планов действий: если X, то Y

## Исправляет искажения
- [[Money illusion]]
- [[Moral credential bias]]
- [[Negativity bias]]

## Связанные методы
- [[Track record analysis]]
- [[Calibration training]]

## Применяется к ошибкам
- [[Poisoning the well]]
- [[Post hoc ergo propter hoc]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Implementation intentions»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
