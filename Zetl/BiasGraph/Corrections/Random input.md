# Random input

## Описание

Введение случайного стимула для генерации новых связей

## Исправляет искажения
- [[Reactance]]
- [[Reality tunnel]]
- [[Recency bias]]

## Связанные методы
- [[Seek disconfirming evidence]]
- [[Steel-manning]]

## Применяется к ошибкам
- [[Sweeping generalization]]
- [[Taboo fallacy]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Random input»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
