# Fermi question

## Описание

Разбиение сложного вопроса на подсчитываемые части

## Исправляет искажения
- [[Plan continuation bias]]
- [[Projection bias]]
- [[Pro-innovation bias]]

## Связанные методы
- [[Random input]]
- [[Provocation]]

## Применяется к ошибкам
- [[Special pleading]]
- [[Stolen concept]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Fermi question»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
