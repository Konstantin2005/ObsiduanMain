# Ishikawa diagram

## Описание

Диаграмма «рыбий скелет» для визуализации причинно-следственных связей

## Исправляет искажения
- [[Hindsight bias (advanced)]]
- [[Hostile media effect]]
- [[Hyperbolic discounting]]

## Связанные методы
- [[Risk assessment]]
- [[Sensitivity analysis]]

## Применяется к ошибкам
- [[Modal fallacy]]
- [[Morton's fork]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Ishikawa diagram»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
