# Scenario planning

## Описание

Разработка и анализultiple сценариев развития событий

## Исправляет искажения
- [[Google effect]]
- [[Grass is greener syndrome]]
- [[Group attribution bias]]

## Связанные методы
- [[Ishikawa diagram]]
- [[Pareto analysis]]

## Применяется к ошибкам
- [[Is-ought fallacy]]
- [[Just-world fallacy]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Scenario planning»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
