# If-then planning

## Описание

Детальное планирование реакций на сценарии

## Исправляет искажения
- [[Negativity bias]]
- [[Not Invented Here]]
- [[Omission bias]]

## Связанные методы
- [[Probabilistic thinking]]
- [[Confidence intervals]]

## Применяется к ошибкам
- [[Psychologist's fallacy]]
- [[Questionable cause]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «If-then planning»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
