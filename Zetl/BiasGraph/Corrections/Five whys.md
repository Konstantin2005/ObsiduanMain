# Five whys

## Описание

Цепочка из пяти вопросов «почему» для выявления корневой причины

## Исправляет искажения
- [[Hard-easy effect]]
- [[Hindsight bias (advanced)]]
- [[Hostile media effect]]

## Связанные методы
- [[Decision matrix]]
- [[Risk assessment]]

## Применяется к ошибкам
- [[Magical thinking]]
- [[Modal fallacy]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Five whys»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
