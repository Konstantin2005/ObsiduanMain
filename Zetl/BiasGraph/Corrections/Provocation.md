# Provocation

## Описание

Сознательное нарушение правил для выхода за рамки

## Исправляет искажения
- [[Reality tunnel]]
- [[Recency bias]]
- [[Rhyme as reason]]

## Связанные методы
- [[Steel-manning]]
- [[Charity principle]]

## Применяется к ошибкам
- [[Taboo fallacy]]
- [[Texas sharpshooter]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Provocation»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
