# 1/N heuristic

## Описание

Равное распределение ресурсов между вариантами

## Исправляет искажения
- [[Planning fallacy]]
- [[Anchoring on irrelevant]]
- [[Подтверждающее искажение]]

## Связанные методы
- [[Мысленный эксперимент]]
- [[Альтернативная гипотеза]]

## Применяется к ошибкам
- [[Dunning-Kruger error]]
- [[Ошибка подгонки]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «1/N heuristic»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
