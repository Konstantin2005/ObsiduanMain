# Fermi estimation

## Описание

Приближённая оценка через разбиение на простые компоненты

## Исправляет искажения
- [[Overconfidence effect]]
- [[Pessimism bias]]
- [[Plan continuation bias]]

## Связанные методы
- [[Reverse brainstorming]]
- [[Assumption busting]]

## Применяется к ошибкам
- [[Single cause fallacy]]
- [[Slippery slope]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Fermi estimation»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
