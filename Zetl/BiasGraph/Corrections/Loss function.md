# Loss function

## Описание

Определение штрафа за различные типы ошибок

## Исправляет искажения
- [[Unit bias]]
- [[Uniqueness bias]]
- [[Verbatim effect]]

## Связанные методы
- [[Optimizing]]
- [[Bounded rationality]]

## Применяется к ошибкам
- [[Tu quoque]]
- [[Whataboutism]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Loss function»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
