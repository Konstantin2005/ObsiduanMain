# Decision matrix

## Описание

Матрица для количественной оценки альтернатив

## Исправляет искажения
- [[Identifiable victim effect]]
- [[Impact bias]]
- [[Information bias]]

## Связанные методы
- [[Regret minimization]]
- [[Second-order effects analysis]]

## Применяется к ошибкам
- [[Naturalistic fallacy]]
- [[Negative proof]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Decision matrix»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
