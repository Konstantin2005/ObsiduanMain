# Time horizon analysis

## Описание

Рассмотрение последствий на разных временных масштабах

## Исправляет искажения
- [[Law of small numbers]]
- [[Less-is-more effect]]
- [[Loss aversion]]

## Связанные методы
- [[Implementation intentions]]
- [[Temptation bundling]]

## Применяется к ошибкам
- [[One-sidedness]]
- [[Oversimplification]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Time horizon analysis»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
