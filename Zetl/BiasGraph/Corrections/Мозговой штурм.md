# Мозговой штурм

## Описание

Свободная генерация идей без критики для расширения пространства

## Исправляет искажения
- [[Bandwagon effect]]
- [[Bias blind spot]]
- [[Cheerleader effect]]

## Связанные методы
- [[Матрица решений]]
- [[Агентный подход]]

## Применяется к ошибкам
- [[Denying the antecedent]]
- [[Dicto simpliciter]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Мозговой штурм»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
