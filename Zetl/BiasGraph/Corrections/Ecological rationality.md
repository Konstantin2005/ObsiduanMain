# Ecological rationality

## Описание

Адаптация методов решения к среде

## Исправляет искажения
- [[Automation bias]]
- [[Authority bias]]
- [[Contrast effect]]

## Связанные методы
- [[1/N heuristic]]
- [[Equally weighted model]]

## Применяется к ошибкам
- [[Ecological fallacy]]
- [[Simpson's paradox]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Ecological rationality»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
