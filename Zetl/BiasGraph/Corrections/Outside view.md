# Outside view

## Описание

Взгляд со стороны, использование данных о аналогичных случаях

## Исправляет искажения
- [[Less-is-more effect]]
- [[Loss aversion]]
- [[Mere exposure effect]]

## Связанные методы
- [[Temptation bundling]]
- [[If-then planning]]

## Применяется к ошибкам
- [[Oversimplification]]
- [[Paradise lost fallacy]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Outside view»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
