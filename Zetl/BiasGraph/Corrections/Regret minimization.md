# Regret minimization

## Описание

Выбор, минимизирующий потенциальные сожаления в будущем

## Исправляет искажения
- [[Inter-group bias]]
- [[Irrational escalation]]
- [[Law of small numbers]]

## Связанные методы
- [[Reference class forecasting]]
- [[Pre-commitment]]

## Применяется к ошибкам
- [[Non sequitur]]
- [[Nutshell fallacy]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Regret minimization»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
