# Альтернативная гипотеза

## Описание

Формулировка конкурирующих объяснений для каждого наблюдения

## Исправляет искажения
- [[Эффект толпы]]
- [[Искажение выжившего]]
- [[Эффект свиньи]]

## Связанные методы
- [[Критическое мышление]]
- [[Метод исключения]]

## Применяется к ошибкам
- [[Ad hominem]]
- [[Appeal to authority]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Альтернативная гипотеза»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
