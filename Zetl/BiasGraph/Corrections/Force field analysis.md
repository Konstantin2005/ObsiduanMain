# Force field analysis

## Описание

Анализ сил, способствующих и препятствующих изменению

## Исправляет искажения
- [[Grass is greener syndrome]]
- [[Group attribution bias]]
- [[Hard-easy effect]]

## Связанные методы
- [[Pareto analysis]]
- [[Cost-benefit analysis]]

## Применяется к ошибкам
- [[Just-world fallacy]]
- [[Ludic fallacy]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Force field analysis»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
