# Root cause analysis

## Описание

Систематический поиск корневой причины проблемы

## Исправляет искажения
- [[Group attribution bias]]
- [[Hard-easy effect]]
- [[Hindsight bias (advanced)]]

## Связанные методы
- [[Cost-benefit analysis]]
- [[Decision matrix]]

## Применяется к ошибкам
- [[Ludic fallacy]]
- [[Magical thinking]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Root cause analysis»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
