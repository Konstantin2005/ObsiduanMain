# Список контрольных точек

## Описание

Определённый перечень этапов проверки перед действием

- [[Эффект плато]]
- [[Фундаментальная ошибка атрибуции]]
- [[Групповая поляризация]]

## Связанные методы

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Список контрольных точек»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
