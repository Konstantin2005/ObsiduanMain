# Challenge assumptions

## Описание

Систематическая проверка всех принятых допущений

## Исправляет искажения
- [[Recency bias]]
- [[Rhyme as reason]]
- [[Risk compensation]]

## Связанные методы
- [[Charity principle]]
- [[Bayesian updating]]

## Применяется к ошибкам
- [[Texas sharpshooter]]
- [[Truth by assertion]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Challenge assumptions»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
