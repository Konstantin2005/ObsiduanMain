# Pre-mortem analysis

## Описание

Анализ проекта до его начала, предсказывание причин провала

## Исправляет искажения
- [[Focusing effect]]
- [[Framing effect]]
- [[Gambler's fallacy (probability)]]

## Связанные методы
- [[Scenario planning]]
- [[Force field analysis]]

## Применяется к ошибкам
- [[Hedging fallacy]]
- [[Hasty generalization]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Pre-mortem analysis»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
