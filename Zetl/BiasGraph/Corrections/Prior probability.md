# Prior probability

## Описание

Оценка начальной вероятности до получения данных

## Исправляет искажения
- [[Subadditivity effect]]
- [[Survivorship bias (advanced)]]
- [[System justification]]

## Связанные методы
- [[Loss function]]
- [[Risk aversion accounting]]

## Применяется к ошибкам
- [[Wrong direction fallacy]]
- [[Gambler's fallacy (error)]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Prior probability»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
