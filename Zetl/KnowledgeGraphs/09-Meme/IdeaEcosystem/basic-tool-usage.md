# Basic Tool Usage

Type: Idea (Symbiont)

## Overview
The fundamental use of tools to extend human capabilities and solve problems.

## Core Principle
Basic tool usage leverages external objects to overcome human limitations and achieve more than would be possible with biological capabilities alone.
