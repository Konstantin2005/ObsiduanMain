
## Что это

Специальная область памяти внутри Heap.

Содержит уникальные строки.

---

## Пример

```java
String a = "hello";
String b = "hello";
```

В памяти создаётся один объект.

```java
a == b
```

Вернёт:

```java
true
```

---

## new String()

```java
String a = new String("hello");
String b = new String("hello");
```

Создаются новые объекты.

```java
a == b
```

Вернёт:

```java
false
```

---

## Зачем нужен

Уменьшает потребление памяти.

Особенно важно для приложений с миллионами строк.
