# Hindsight Bias Error

## Overview
The error of believing, after an event has occurred, that one would have predicted or expected the outcome, distorting memory and judgment.

## Detailed Content
Hindsight bias error occurs when people reconstruct their past predictions to match actual outcomes, creating a false sense of foresight and distorting learning opportunities.

### Error Patterns
- **Memory distortion**: Reconstructing past beliefs to match current knowledge
- **False certainty**: Believing one "knew it all along"
- **Learning distortion**: Overestimating predictive accuracy

### Common Contexts
- Financial market analysis
- Medical diagnosis reflection
- Project outcome evaluation
- Personal decision-making review

### Detection Methods
- Keep records of initial predictions
- Compare predictions with actual outcomes
- Use probability assessments
- Seek objective evidence
