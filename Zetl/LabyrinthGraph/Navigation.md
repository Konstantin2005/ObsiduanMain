# Навигация по лабиринту

## Как пользоваться картой

1. Начните с любой комнаты
2. Следуйте по дверям, открывая их ключами
3. Остерегайтесь ловушек
4. Исследуйте тупики в поисках секретов
5. Доберитесь до босс-комнаты
