
Маска подсети определяет, какая часть IP‑адреса относится к сети, а какая — к хосту. Она используется для маршрутизации и разделения сети на подсети.

Чаще всего маску записывают в виде CIDR, например `/24`.

---

## Пример

```
IP:    192.168.1.10
Mask:  255.255.255.0
CIDR:  192.168.1.0/24
```

Это означает:
- сеть: `192.168.1.0`
- хосты: `192.168.1.1` — `192.168.1.254`
- broadcast: `192.168.1.255`

---

## CIDR и количество адресов

- `/24` → 256 адресов (254 доступно)
- `/25` → 128 адресов (126 доступно)
- `/26` → 64 адреса (62 доступно)
- `/27` → 32 адреса (30 доступно)

Формула: `2^(32 - prefix)`

---

## Частый вопрос

**Сколько IP‑адресов у сети /24?**  
Всего **256**, из них **254 доступно** (1 — адрес сети, 1 — broadcast).

---

## Как считать вручную

1) Определите количество бит хоста: `host_bits = 32 - prefix`.
2) Количество адресов: `2^host_bits`.
3) Диапазон подсети = кратен размеру блока.

Пример для `/26`:
- `host_bits = 32 - 26 = 6`
- `2^6 = 64` адреса
- размер блока = 64 → подсети: .0, .64, .128, .192

Пример для `192.168.1.70/26`:
- ближайшая сеть: `192.168.1.64`
- broadcast: `192.168.1.127`
- хосты: `192.168.1.65` — `192.168.1.126`

---

## Быстрый расчёт

```bash
ipcalc 192.168.1.10/24
```

## Роль маски подсети

Маска подсети показывает, какая часть IP‑адреса относится к сети, а какая — к хосту.

С её помощью устройство понимает:

- находится ли адрес назначения в той же подсети;
- отправлять пакет напрямую или через шлюз;
- сколько адресов доступно в подсети.

Пример:

`192.168.1.10/24` → сеть `192.168.1.0`, хост‑часть — последний октет.
