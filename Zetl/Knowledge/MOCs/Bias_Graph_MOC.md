## Key Relationships

### Bias → Error (causes)
Each bias connects to 2-5 thinking errors it commonly produces.

### Error → Consequences (leads_to)
Each error leads to 2-5 negative outcomes or consequences.

### Correction → Bias (fixes)
Each correction addresses 2+ biases it can mitigate.

### Bias → Bias (amplifies)
