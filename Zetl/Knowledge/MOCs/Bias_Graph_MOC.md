# Bias Graph

## Overview
A comprehensive map of cognitive biases, thinking errors, and correction strategies that form an interconnected network showing how biases cause errors, how errors lead to consequences, and how corrections fix biases.

## Link Types

### causes
Biases that lead to thinking errors

### leads_to
Errors that result in negative consequences

### fixes
Corrections that address specific biases

### amplifies
Biases that reinforce or amplify other biases

## Key Relationships

### Bias → Error (causes)
Each bias connects to 2-5 thinking errors it commonly produces.

### Error → Consequences (leads_to)
Each error leads to 2-5 negative outcomes or consequences.

### Correction → Bias (fixes)
Each correction addresses 2+ biases it can mitigate.

### Bias → Bias (amplifies)
Biases that create amplification cycles and feedback loops.
