
MAC‑адрес — аппаратный адрес сетевого интерфейса на канальном уровне (L2). Обычно 48 бит, записывается как `AA:BB:CC:DD:EE:FF`.

---

## Что важно понимать

- Используется в пределах локальной сети (L2), не маршрутизируется как IP.
- Уникален для интерфейса (обычно задаётся производителем).
- Применяется в ARP, коммутации и фильтрации.

---

## Примеры

```bash
ip link show
ip addr show
```

Пример вывода:
```
link/ether 08:00:27:12:34:56
```

## MAC vs IP

- **MAC** — аппаратный адрес сетевой карты на канальном уровне (L2). Используется внутри одной сети.
- **IP** — логический адрес на сетевом уровне (L3). Используется для маршрутизации между сетями.

MAC “локальный”, IP “маршрутный”.

---

## On-call диагностика

Проверить интерфейс и MAC:
```bash
ip link show
ip -br link
```

Проверить связку IP -> MAC в сегменте:
```bash
ip neigh
arp -a
```

Симптомы проблем:
- частое изменение MAC для одного IP (ARP spoofing/конфликт);
- отсутствующая запись MAC при наличии L3 маршрута (проблема L2).

---

## Типовые ошибки

- Ожидание маршрутизации по MAC между подсетями.
- Жесткая привязка security-правил только к MAC без IP/identity уровня.
- Игнорирование MAC-randomization на клиентских устройствах.
