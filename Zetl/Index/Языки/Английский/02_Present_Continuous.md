Present Continuous  
  
## 📌 Use  
- happening now  
- temporary actions  
  
---  
  
## 📌 Structure  
am/is/are + V-ing  
  
- I am working  
- She is reading  
  
---  
  
## 📌 Rules for -ing  
- work → working  
- write → writing  
- run → running  
  
---  
  
## 📌 Negative  
am/is/are + not + V-ing  
  
---  
  
## 📌 Questions  
Am/Is/Are + subject + V-ing?
