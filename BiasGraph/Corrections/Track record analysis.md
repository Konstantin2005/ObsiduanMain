# Track record analysis

## Описание

Анализ прошлых результатов для оценки будущих

## Исправляет искажения
- [[Omission bias]]
- [[Optimism bias]]
- [[Ostrich effect]]

## Связанные методы
- [[Fermi estimation]]
- [[Order of magnitude]]

## Применяется к ошибкам
- [[Red herring]]
- [[Reification]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Track record analysis»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
