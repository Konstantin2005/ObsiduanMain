Прогнозирование на основе статистики класса подобных проектов

- [[Loss aversion]]
- [[Mere exposure effect]]
- [[Money illusion]]

## Связанные методы
- [[If-then planning]]

1. Определите проблему или искажение
2. Выберите метод «Reference class forecasting»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
