# Cost-benefit analysis

## Описание

Систематическое сравнение затрат и выгод для каждого варианта

## Исправляет искажения
- [[Hyperbolic discounting]]
- [[Identifiable victim effect]]
- [[Impact bias]]

## Связанные методы
- [[Expected value calculation]]
- [[Regret minimization]]

## Применяется к ошибкам
- [[Moving the goalposts]]
- [[Naturalistic fallacy]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Cost-benefit analysis»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
