# Likelihood ratio

## Описание

Отношение правдоподобий данных при двух гипотезах

## Исправляет искажения
- [[Survivorship bias (advanced)]]
- [[System justification]]
- [[Time-saving bias]]

## Связанные методы
- [[Risk aversion accounting]]
- [[Prospect theory application]]

## Применяется к ошибкам
- [[Gambler's fallacy (error)]]
- [[Genetic fallacy (advanced)]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Likelihood ratio»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
