# Аргументация со справедливой стороны

## Описание

Лучшее представление позиции оппонента перед её критикой

- [[Эффект Дunningа-Крюгера]]
- [[Иллюзия контроля]]
- [[Эффект плато]]

## Связанные методы

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Аргументация со справедливой стороны»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
