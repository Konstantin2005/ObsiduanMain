# Expected utility

## Описание

Расчёт ожидаемой полезности для принятия решений

## Исправляет искажения
- [[Time-saving bias]]
- [[Unit bias]]
- [[Uniqueness bias]]

## Связанные методы
- [[Satisficing]]
- [[Optimizing]]

## Применяется к ошибкам
- [[Tone policing]]
- [[Tu quoque]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Expected utility»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
