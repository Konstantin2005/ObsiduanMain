# Order of magnitude

## Описание

Оценка порядка величины для быстрой проверки

## Исправляет искажения
- [[Pessimism bias]]
- [[Plan continuation bias]]
- [[Projection bias]]

## Связанные методы
- [[Assumption busting]]
- [[Random input]]

## Применяется к ошибкам
- [[Slippery slope]]
- [[Special pleading]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Order of magnitude»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
