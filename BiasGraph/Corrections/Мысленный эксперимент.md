# Мысленный эксперимент

## Описание

Создание гипотетических сценариев для проверки логики и последствий идей

## Исправляет искажения
- [[Подтверждающее искажение]]
- [[Эффект толпы]]
- [[Искажение выжившего]]

## Связанные методы
- [[Факт-чекинг]]
- [[Критическое мышление]]

## Применяется к ошибкам
- [[Соломенное чучело]]
- [[Ad hominem]]

## Как использовать
1. Определите проблему или искажение
2. Выберите метод «Мысленный эксперимент»
3. Примените пошагово
4. Проверьте результат
5. Запишите выводы
