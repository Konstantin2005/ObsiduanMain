# Система двухтипных заметок для графа знаний в Obsidian

## ОБЩИЕ ПРАВИЛА

1. Каждая заметка имеет ровно один из двух типов
2. Ссылки между заметками показывают отношения типов
3. Названия заметок содержат префикс типа в квадратных скобках
4. Всё информация передается только через ссылки, без YAML
5. Граф оптимизирован для 2000+ заметок

---

## ВАРИАНТ 1: ТЕХНОЛОГИЯ + ПРОБЛЕМА

### Назначение
Структура "решение-проблема": каждая технология связана с проблемами, которые она решает.

### Тип 1: [T] Technology
**Что это:** конкретные инструменты, библиотеки, фреймворки, сервисы, протоколы

**Примеры имён:**
- [x] Redis
- [T] PostgreSQL
- [T] FastAPI
- [T] Docker Container
- [T] JWT Token
- [T] WebSocket protocol

**Содержимое заметки:**
# [T] Redis

Быстрое хранилище данных в памяти с поддержкой структур данных.
