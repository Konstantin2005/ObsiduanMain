
YAML — это язык для представления данных, который позволяет хранить их в компактном и читаемом формате.

Язык похож на XML и JSON, но использует более минималистичный синтаксис. YAML обычно применяют для создания конфигурационных файлов.

```YAML
--- 
#ключ значение
name: Иван Иванов
age: 37
```

![[Image (2).png]]


YAML по умолчанию знает тип данных значения, но вы можете явно указать тип через `!!`:

```YAML
---
message: !!str Джон Уик очень целеустремленный человек.
number: !!int 13
float_number: !!float 3.14 
```
