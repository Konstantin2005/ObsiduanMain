#2Спринт
Здесь приходится использовать дополнительную переменную, а также два оператора `break`, так как необходимо выйти из двух циклов. На самом деле Go даёт возможность для `break` и `continue` указывать цикл, к которому они относятся. Для этого перед циклом нужно указать метку-идентификатор и двоеточие. Теперь любой `break <метка-идентификатор>` или `continue <метка-идентификатор>` будут относиться к этому циклу. Метка перед циклом позволяет в дальнейшем идентифицировать его и указать, что операторы `break` или `continue` применяется именно к этому циклу. Так упрощается использование этих операторов во вложенных циклах.

```GO
package main

import "fmt"

func main() {
top: // метка
    for i := 1; i <= 1000; i++ {
        for j := 1; j <= 1000; j++ {
            if i*j > 65535 {
                fmt.Println(i, "*", j, "=", i*j)
                break top  // break относится к циклу после метки top
            }
        }
    }
}
```
