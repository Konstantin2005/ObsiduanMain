**Input:** nums = [1,1,2]
**Output:** 2, nums = [1,2,_]


It is necessary to add all the unique elements to the top of the list and return their number.


![[Pasted image 20260403183118.png]]

K++ When I encounters a new element  
And adds new items to the top of the list.

```Go
func removeDuplicates(nums []int) int {

    if len(nums) == 0 {
        return 0
    }


    k := 1

    for i := 1; i < len(nums); i++ {
        if nums[i] != nums[i-1] {
            nums[k] = nums[i]
            k++
        }
    }


    return k

}
```
