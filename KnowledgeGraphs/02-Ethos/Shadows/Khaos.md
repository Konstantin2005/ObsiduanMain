# 🌑 Хаос

**Тип:** Тень
**Кластер:** [[Свобода]]

---

Бесконтрольная свобода разрушает структуры, необходимые для жизни. Когда никто никому не должен — каждый за себя.

---

**Механизм усиления:** При чрезмерном применении Свобода порождает аномию: отсутствие норм, правил, ответственности. Свобода без границ становится разрушительной.
