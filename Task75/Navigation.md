- 🌐 [[MOC - Comprehensive Knowledge Graph]] — **Универсальная система знаний** — Всеобъемлющая интегрированная система знаний, объединяющая все аспекты человеческой познания в единое целое.
- 📚 [[MOC - Knowledge]] — **Сеть фактов, концепций и теорий** — Центральный граф для базовых знаний.

- ❓ [[MOC - QuestionFractal]] — **Исследовательский фрактал открытых вопросов** — Граф для исследования неизвестного.

## Межграфовые переходы

Чтобы перейти из одного графа в другой:

1. Найдите мостовую заметку в текущем графе
2. Перейдите по `[[MOC - TargetGraph]]` в другой граф
3. Используйте graph view для визуализации связей
