Нам дан массив 
если все числа все положительное то сумма N
если все числа отрицательные то сумма -1
не надо брать отрицательные числа

проходимся по массиву 
```javascript
var maxSubArray = function(nums) {
    let res = nums[0];
    let total = 0;

    for (let n of nums) {
        if (total < 0) {
            total = 0;
        }

        total += n;
        res = Math.max(res, total);
    }
    
    return res;    
};
```


мы создаём 2 переменные 1 для финального результата а вторая для суммы промежуточных значений

проходимся по всему массиву при помощи цикла FOR первая тернарная ветка отвечает за то что если наша промежуточная сумма не равна нулю
