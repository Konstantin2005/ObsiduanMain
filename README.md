# README.md

## Система заметок и управления документами для API разработки

### Обзор

Эта система обеспечивает конвертацию данных и управление документами с использованием современных файловых серверов и инфраструктуры микросервисов.

### Архитектура

```
Сервис парсинга -> Обработка синтаксисов
Сервис передачи данных -> Обработка данных и API
Ядро приложения -> Управление плагинами и потоком работы
```

### Основные компоненты

1. **Сервис парсинга**: Обрабатывает различные синтаксисы документов (markdown, template, plain_text)
2. **Сервис передачи данных**: Предоставляет REST API для взаимодействия с документами
3. **Ядро приложения**: Управляет плагинами и многопоточностью
4. **Сервис нотаций**: Интегрируется с Notion для синхронизации данных
5. **Инфраструктура файловых серверов**: Поддерживает множественные файловые системы (S3, GCS, локальный файл)

### Структура API

#### Заметки

- `GET /api/notes` - Получение списка заметок с пагинацией
- `POST /api/notes` - Создание новой заметки
- `GET /api/notes/{id}` - Получение заметки по ID
- `PUT /api/notes/{id}` - Обновление заметки
- `DELETE /api/notes/{id}` - Удаление заметки
- `POST /api/notes/{id}/export` - Экспорт заметки в различных форматах

#### Контексты

- `GET /api/contexts` - Получение контекстов
- `GET /api/contexts/{id}` - Получение контекста по ID
- `POST /api/contexts` - Создание контекста
- `PUT /api/contexts/{id}` - Обновление контекста
- `DELETE /api/contexts/{id}` - Удаление контекста

#### Статические файлы

- `GET /api/static/{path}` - Получение статических файлов

#### Статистика

- `GET /api/stats` - Получение статистики системы

#### Здоровье

- `GET /api/health` - Проверка состояния сервиса

### Использование

```bash
# Установите зависимости
npm install

# Запустите бэкенд сервер
npm run start:backend

# Запустите фронтенд сервер
npm run start:frontend

# Запустите тесты
npm run test
```

### Разработка

#### Бэкэнд

```bash
# Запустите бэкенд в режиме разработки
cd backend
npm run dev
```

#### Фронтэнд

```bash
# Запустите фронтенд в режиме разработки
cd frontend
npm run dev
```

### Тестирование

#### Единичные тесты

```bash
# Запустите юнит-тесты
npm run test:unit

# Запустите интеграционные тесты
npm run test:integration

# Запустите эндто- и фронтенд-тесты
npm run test:e2e
```

#### Сценарии тестирования

В системе есть комплексная система тестирования, которая охватывает:

1. **Тест-кейсы**: Стандартные сценарии тестирования
2. **Edge cases**: Нетипичные сценарии
3. **Failure scenarios**: Сценарии с ошибками
4. **Validation rules**: Тесты валидации

### Критические модули

1. **Плагин**: Синтаксисы, предоставляемые плагинами
2. **Парсер**: Базовый парсер для каждого синтаксиса
3. **Получатель данных**: Получение данных из файловых серверов
4. **Сервис нотаций**: Процесс работы с Notion
5. **База данных**: Хранение данных синтаксисов и заметок
6. **API сервера**: REST API сервера
7. **Файловые серверы**: Множественные файловые серверы

### Машина переходов времени

- **Версия:** Время
- **Состояние:** Текущее состояние процесса работы
- **Действие:** Время в секундах

### Требования к обеспечению качества

- **Производительность:** Быстрая конвертация заметок, быстрое взаимодействие с API
- **Надежность:** Обновление данных из файловых серверов, обработка исключений
- **Масштабируемость:** Множественные файловые серверы, модульная архитектура
- **Поддержка:** Руководства, тесты, логи
