# Соц Капитал — Дашборд

## Все люди

```dataview
TABLE
circle as "Круг",
trust as "Доверие",
closeness as "Близость",
city as "Город",
tags as "Теги"
FROM "Calendula/Соц Капитал"
WHERE type = "person"
SORT circle ASC, trust DESC
```

## Статистика

```dataview
TABLE WITHOUT ID
rows.file.name as "Имя"
FROM "Calendula/Соц Капитал"
WHERE type = "person"
GROUP BY circle as "Круг"
FLATTEN length(rows) as "Количество"
SORT circle ASC
```

```dataview
TABLE WITHOUT ID
"Среднее доверие: " + round(avg(trust), 1) as "",

"Всего людей: " + length(rows) as ""
```
