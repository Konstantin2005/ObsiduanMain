# Финансы

Локальный мини-трекер для учёта денег.

## Что здесь есть

- `index.html` - автономная страница для ввода доходов и расходов
- автоматический подсчёт за выбранный день, месяц и год
- экспорт и импорт JSON для резервных копий
- таблица всех записей и сводка по категориям

## Как пользоваться

1. Открой `index.html` в браузере.
2. Добавляй операции: дата, тип, сумма, категория, комментарий.
3. Выбирай дату в блоке сводки - суммы за день, месяц и год пересчитаются автоматически.
4. Делай экспорт JSON, чтобы хранить резервную копию в vault.

## Логика подсчёта

- `День` - все операции на выбранную дату
- `Месяц` - все операции выбранного месяца
- `Год` - все операции выбранного года
- баланс считается как `доход - расход`
