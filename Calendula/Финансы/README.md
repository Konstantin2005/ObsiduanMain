# Финансы

Здесь теперь две параллельные системы:

1. `index.html` - мини-приложение для быстрого ручного учёта
2. `Days/` + `Scripts/` - Obsidian-форма для ежедневного учёта жилья и еды

## Ежедневный учёт

Папка для ежедневных заметок:
- [Финансы/Days](/C:/obsidian/Main/Calendula/Финансы/Days)

Шаблон дня:
- [Финансы/Templates/день.md](/C:/obsidian/Main/Calendula/Финансы/Templates/день.md)

Скрипты:
- [Финансы/Scripts/создать-дни-год.ps1](/C:/obsidian/Main/Calendula/Финансы/Scripts/создать-дни-год.ps1)
- [Финансы/Scripts/собрать-год.ps1](/C:/obsidian/Main/Calendula/Финансы/Scripts/собрать-год.ps1)

## Как работает ежедневный вариант

1. Открываешь нужный день в `Финансы/Days`.
2. Заполняешь только числа в разделах `Жильё` и `Еда`.
3. Раз в любое время запускаешь `собрать-год.ps1`.
4. Получаешь один итоговый markdown-файл со сводкой по дням и месяцам.

## Что уже подготовлено

- шаблон одной дневной заметки
- генератор на 365 дней от `2026-06-08`
- скрипт, который собирает всё в один файл
