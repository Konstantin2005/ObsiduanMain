#One

Основные интерфейсы `database/sql` находятся в пакете `driver`. Каждый интерфейс выполняет свою задачу.

Интерфейс `driver.Driver` абстрагирует создание соединения с БД. Единственная функция `Open()` открывает соединение с БД и возвращает объект `driver.Conn` для работы с этим соединением. Вот так выглядит сам интерфейс:

```Go
type Driver interface {
    Open(name string) (Conn, error)
} 
```


Интерфейс `driver.Conn` предоставляет функции для работы с соединением с БД, создания транзакций и подготовки запросов:

- Функция `Prepare()` — подготавливает SQL-запрос для последующего выполнения, возвращает объект `driver.Stmt` для работы с этими запросами.
- Функция `Close()` — закрывает текущее соединение.
- Функция `Begin()` — начинает новую транзакцию, возвращает объект `driver.Tx` для управления транзакциями.

Вот как выглядит интерфейс:

```Go
type Conn interface {
    Prepare(query string) (Stmt, error)
    Close() error
    Begin() (Tx, error)
} 
```
