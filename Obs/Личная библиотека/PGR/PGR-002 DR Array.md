в Go массивы это номурованая последовательность данных.
мы создаем массив и кидаем в четвертый элемент но по индексу это будет 5 так что все правильно 
```go
var arr [5]int
arr[4] = 100
fmt.Println("set:", arr) // set: [0 0 0 0 100]
```

длина массива она в массивах сразу изветсна
```go 
fmt.Println("len:", len(arr))
```


Можно инициализировать массив при объявлении:

```go
arr := [5]int{1, 2, 3, 4, 5}
fmt.Println("init:", arr)
// init: [1 2 3 4 5]
